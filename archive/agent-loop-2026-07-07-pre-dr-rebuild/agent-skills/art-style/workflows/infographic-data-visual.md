# Infographic / Data-Visual

Educational, authority-building layouts with structured information presentation. Data visualization elements, flat icons, and clean grid layouts signal credibility and expertise. The viewer learns something in a single glance.

**Prerequisites:** Hook-bank file must exist. Main Agent triggers hook-methodology skill first.

---

## Style Overview

**What it is:** Information-dense, grid-based compositions that present data, comparisons, step breakdowns, or statistics as the primary visual content. Flat icon illustrations, numbered sections, divider lines, and labeled callouts create a factual, authoritative tone through visual structure alone.

**Why it works:**
- Structure signals credibility — organized information feels trustworthy
- Educational content earns engagement (saves, shares) not just impressions
- "Data-backed" visual framing increases perceived authority
- Information density gives viewers a reason to pause and read (dwell time)
- Comparison and checklist layouts tap into decision-making psychology
- Grid-based structure is inherently mobile-friendly — easy to scan vertically

**Visual Characteristics:**

| Element | Specification |
|---------|---------------|
| Layout | Grid-based, structured, organized — visual order signals credibility |
| Data elements | Comparison charts, step breakdowns, numbered lists, progress bars, check/cross marks, star ratings, percentage indicators |
| Icons | Flat, consistent-size illustrations (not 3D, not detailed) |
| Typography | Multiple text sizes creating information hierarchy |
| Background | White or very light gray — clinical, clean, professional |
| Dividers | Lines, section separators, numbered headers creating structure |

## Step 4: Visual Concept Creation

For each hook, determine the information architecture:

### Layout Type Selection

| Hook Psychology | Layout Type | Why |
|----------------|-------------|-----|
| Pain/Problem | **Comparison (This vs. That)** — left side shows the painful status quo, right side shows the solution | The data makes the pain quantifiable and the solution clear |
| Education/Value | **Steps / Numbered List** — 3-5 steps presented as a visual process | Education hooks demand structured, sequential information |
| Social Proof | **Stats Grid** — key numbers (customers, ratings, results) presented as a data dashboard | Social proof is most convincing as aggregated data |
| Urgency/Scarcity | **Progress Bar / Timer Visual** — data showing a closing window or depleting resource | Urgency is amplified when quantified (87% claimed, 3 days left) |
| Transformation | **Before/After Split** — two data columns showing the measurable difference | Transformation claims are credible when supported by numbers |
| Curiosity/Question | **Checklist / Reveal** — items with check/cross showing surprising results | Curiosity hooks pair with data that delivers the "answer" |

### Information Hierarchy

Every infographic layout follows this visual priority:

1. **Headline** (top) — the hook text, framing the data below
2. **Key Stat** — the single most important number or comparison, rendered large
3. **Supporting Data** — 2-4 secondary data points providing context
4. **CTA** (bottom) — action step after the viewer has been educated

### Icon Selection

Icons are flat, simple, and consistent in size and weight:
- Use outline-style icons (not filled, not 3D)
- Maximum 4-6 icons per composition
- All icons at the same visual weight (stroke width, size)
- Icons represent categories or steps, not decorative embellishment
- Brand primary color for icon strokes, neutral for backgrounds

## Step 5: Design Principles

### 1. Structure IS the Design
- The grid layout communicates authority without needing to claim it
- Every section has clear boundaries (divider lines, background alternation, spacing)
- Alignment is precise — nothing is casually placed
- The viewer should feel they're looking at organized information, not art

### 2. Information Hierarchy Through Scale
- Key stat or number rendered 3-5x larger than body text
- Headline at top sets the frame for interpretation
- Supporting data at consistent, readable size
- CTA at smallest text but in accent color for attention

### 3. Clean, Professional Color
- Clinical base: white (#FFFFFF) or very light gray (#F5F5F5) background
- Brand primary for headline and key data points
- Brand secondary for dividers, section backgrounds, supporting elements
- Accent sparingly — reserved for the single most important number and CTA
- Muted overall — authority from structure, not color intensity

### 4. Data Visualization Elements
- Percentage bars: horizontal bars showing proportional data, filled in brand primary
- Check/cross marks: green checks, red or gray crosses for comparison grids
- Star ratings: visual stars (filled/empty) for review or quality indicators
- Numbered circles: section headers with circled numbers for process steps
- Progress indicators: partially-filled rings or bars for status/urgency

### 5. Typography as Information Architecture
- Clean sans-serif throughout — no decorative fonts
- Multiple text sizes create information hierarchy:
  - Headline: 28-32pt equivalent, bold, brand primary
  - Section headers: 18-22pt equivalent, semibold
  - Body text: 14-16pt equivalent, regular weight, neutral dark
  - Key statistics: 36-48pt equivalent, bold, accent color
- Numbers and statistics rendered large and bold as visual anchors

### 6. Section Separation
- Light gray (#F0F0F0) alternating section backgrounds for visual rhythm
- Thin divider lines (1-2px) in brand secondary between sections
- Consistent padding (generous) between sections for scannability
- Numbered or labeled section headers for navigation

## Mobile Constraint Integration

Infographic layouts are naturally structured for mobile scanning. Key rules per aspect ratio:

### 4:5 (1080x1350) — Feed Optimized
- Vertical stacking of 3-4 sections
- Each section spans full width
- Data elements (percentage bars, check/cross, icons) sized for thumb-stop clarity
- Headline at top, key stat prominent in upper-center, CTA at 70%

### 1:1 (1080x1080) — Feed Standard / Carousel
- Two-column layout is permitted (large stat left, supporting stats right)
- Or 2x2 grid of equal stats
- Headline at top spanning full width
- CTA bottom-center at 75-80%
- Most flexible format for data dashboard layouts

### 9:16 (1080x1920) — Reels / Stories
- Strict single-column vertical stacking
- One data element per section, sections stacked top-to-bottom
- Headline below 14% safe zone
- CTA above 65% boundary
- Extra generous spacing between sections (the tall format has room)
- Each section self-contained (scannable independently)

## Anti-Patterns

| Never | Instead |
|-------|---------|
| Dense paragraph text | Short labels, numbers, and visual data elements |
| 3D or rendered illustrations | Flat outline icons, consistent stroke weight |
| Dark or moody backgrounds | White or very light gray — clinical authority |
| Decorative or serif fonts | Clean sans-serif throughout, multiple sizes for hierarchy |
| Generic or unverifiable data | Brand-specific, ownable numbers from research |
| Cluttered icon variety | Consistent icon style (all outline, same weight, same size) |
| Data without labels | Every number clearly labeled with what it represents |
| Gradient backgrounds | Flat, clean color — structure is the design element |
| Comparison naming competitors by name | "Industry average" or "typical [category]" as comparison benchmark |
| More than 4-6 data points per frame | Focus on 1 key stat + 2-3 supporting, not comprehensive data dump |

## Quality Checklist

### Information Architecture
- [ ] Layout type matches hook psychology (comparison, steps, stats grid, etc.)
- [ ] 3-4 sections with clear hierarchy
- [ ] Key stat is 3-5x larger than body text
- [ ] Supporting data labeled and readable
- [ ] Information scans top-to-bottom in intended order

### Data Integrity
- [ ] All data points are brand-specific and ownable (Logo Swap Test)
- [ ] Numbers are concrete and verifiable (not vague claims)
- [ ] Comparison is fair (industry average, not named competitors)
- [ ] Data elements (bars, checks, ratings) accurately represent the data

### Visual Design
- [ ] White or light gray background (clinical authority)
- [ ] Brand colors used for hierarchy (primary for headers, accent for key stat)
- [ ] Icons are flat, outline-style, consistent size and weight
- [ ] Section dividers are clean and consistent
- [ ] Generous padding between sections

### Typography
- [ ] Clean sans-serif throughout
- [ ] Multiple text sizes creating clear hierarchy
- [ ] Key statistics rendered large and bold
- [ ] All text 12pt+ equivalent at display size
- [ ] Headline at top frames the data below
