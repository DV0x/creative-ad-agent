The discipline

If a hook can't point to where it came from in the research, it's invention — and invention is weak. The agent picks 3+ different formats per campaign so the 6 ads don't feel same-y.

What each hook carries

One hook =
Format — which of the 10
Source — the exact research element it came from
Target — which buyer it's for
Hook — the headline (≤10 words)
Body + CTA — one proof point, one action
Psychology — why it stops the scroll

Then 5 gates before it passes

Traceable?Owned?Felt? Clear?Theirs?

Owned? = could a competitor run this by swapping the logo? If yes, it's rewritten.

The smart part — built for the ad platform

Entity-ID diversity

The 6 images must each differ on 3 of 5 visual axes — colour, layout, objects, scene, text. Why? So Meta's delivery treats every ad as a genuinely different creative — which helps it find a winner faster instead of seeing six near-duplicates.
