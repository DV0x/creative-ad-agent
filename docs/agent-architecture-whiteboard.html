The two critics — the quality bar

Most "AI ad" tools let the model grade its own homework. Its taste was trained on the same ads as the writer's, so it just blesses generic work. Here a separate seat with a fresh context — it never sees the writer's reasoning — judges by rule, not taste, and when it's unsure, it fails the work. Killing a decent concept costs one draft; shipping a weak one costs the founder's ad budget.

◆ Take-Critic

The concept gate · Opus 4.8

Kills weak ideas on paper, before any render money is spent. Any one failure kills the concept:

  • Mandatory fidelity — checked first. Did it keep every non-negotiable the strategy set (show the real product · the founder's face · stay in brand)? Drop the conversion-driver → hard kill.
  • On-strategy & converts — delivers the exact promise it was assigned, not a drifted one? Would a cold buyer act, or just nod? Does the picture argue the claim, or only decorate?
  • The swap test — strip the logo: could the nearest competitor run this unchanged? Yes → it's generic → dead.
  • Format honesty — a testimonial must look collected (a real screenshot), not a designed brand-poster.
  • No fabrication — every claim sits inside the stated proof. One invented fact → dead.
→ Rank the survivors by who actually sells, name one winner — or REJECT ALL and route the fix upstream.
◆ Render-Critic

The pixel gate · Opus 4.8, sees the image

The concept already passed. This is the finished picture vs. the spec — and: does it actually work in a feed?

  • Held the spec — copy is character-exact and placed right; the product matches the real pack pixel-for-pixel (no fake "Bestseller" badges bolted on); it looks phone-shot, not AI-glossy.
  • Works at thumbnail — the line that sells is legible when shrunk down; the CTA is on the image, not just the caption; the scene is a place someone would really be with this product.
→ PASS (ship it) — or FAIL, each miss tagged "re-render" (the prompt can fix it) or "structural" (the spec itself is wrong — another roll won't help).

It does not re-judge strategy or genericness — that was the take-critic's round. It also never critiques the real product: the pack is ground truth to reproduce, never a defect to hide.

Why it's built this way

The interesting engineering isn't the boxes — it's the choices that keep an autonomous loop honest and cheap.

Files are the hand-off

No agent talks to another. Each writes one file to a shared folder; the next reads it. Clean contracts, fully inspectable after the fact, and re-runnable from any point — resume is just "read the folder and continue."

Critics never see the reasoning

A fresh context judging by rule is the only thing that reliably kills generic work. Ask the same model to critique its own output and it rationalizes and rubber-stamps it.

Two critics, two failure modes

One kills bad ideas cheaply, before a render is paid for. One catches bad pixels before the ad ships. Different jobs, so different eyes — the pixel judge is even multimodal.

Retries that escalate

Not infinite loops. Re-mine ×3, then blame the strategy. Re-render ×1, then blame the spec. When a fix keeps failing, the loop routes the problem up to the layer that's actually wrong instead of grinding.

Sealed & budgeted

Locked tool surface, per-run web-call caps enforced by a hook, a hard dollar ceiling on the whole run. Safe to point at a URL and walk away.

learned the hard way
Critics run one level up

Nesting a critic inside the cell deadlocked the SDK — it backgrounds sub-agents, and the "I'm done" signal never bubbled back. Fix: the orchestrator launches the critics itself, at depth-1, where the async actually resolves.

How we knew the production agent wasn't good enough

The eval — we coded every output by hand

Before rebuilding anything, we ran a proper error analysis on the live production agent: two dozen real campaigns, open-coded to saturation, then clustered by two independent coders. It surfaced 6 repeatable failure modes and one hard number — a 22% quality floor. Everything in the "The agent" tab is the answer to what we found here.

The process — Hamel-style error analysis

We didn't rebuild on a hunch. We ran the canonical loop on the live agent's real outputs: look at the data, code it, cluster it, turn the clusters into graders, measure a baseline, trace the root cause.

1

Collect

~24 real campaigns from prod + staging (~100 ads). An HTML viewer to see each one whole: URL → research → hooks → prompts → images.

2

Open-code

Go output by output, labelling everything wrong or notable — until new campaigns stop adding new labels (saturation).

3

Axial-code ×2

Two independent coders cluster the labels, blind to each other. 6 of 7 clusters converged → the taxonomy locked itself.

4

Rank

Priority = Severity × Frequency × Fixability. → 3× P0, 2× P1, 1× P2.

5

Grade

Each cluster → one binary pass/fail check. 6 code graders run across the whole corpus.

6

Baseline + leak map

22% floor. Then trace every failure to the exact file + line in the prompts that caused it.

Corpus: ~24 campaigns · 16 deep-coded by two coders · 18 run through the code graders. Brands were all real: The Whole Truth, Traya, Mamaearth, Optimum Nutrition, Gonoise, Guardian, DailyObjects, Bewakoof, Theratefinder, Ravila (hotel), Verbisedu, Arjuninfra.

The 6 failure modes

Ranked by Severity × Frequency × Fixability. Each one is a real, repeated pattern across the corpus — not a one-off.

P0

Concept-to-prompt loss

11/16 · critical

The hook copy exists — but the image prompt drops it, so the headline never makes it into the picture.

Optimum Nutrition: 6 of 7 images generated with no headline at all.
P0

Reference image ignored

7–8/16 · critical

User uploads real product / room photos; the agent invents generic AI versions instead — or never asks for photos when the vertical clearly needs them.

Ravila hotel: no photos requested → a hallucinated generic luxury hotel.
P0

Wrong-brand / locale

6/16 · 1 catastrophic

Research targets the wrong entity — a domain redirect, wrong currency, wrong country. The whole campaign is built on a broken foundation.

Mamaearth: mamaearth.in silently redirected to the US site → entire campaign for the wrong brand.
P1

Fabricated / amplified proof

7–9/16 · critical

The agent invents a stat, badge or testimonial — or stretches a real number into a claim it doesn't support. A Meta-policy and trust risk.

Theratefinder: "856 reviews" → "16,000+ approved"; a fabricated "Dermatologist-Tested" badge on Mamaearth.
P1

Template-grade generic hook

9/16 · high

The whole hook construction works for any brand in the category. Swap the logo and a competitor could run it unchanged.

Any hotel: "Premium hotel rooms. 50% less than [landmark]." — any hotel, any city.
P2

Soft / channel-mismatched CTA

8/16 · high

Exploratory "See your options" instead of an action — or a CTA that fits the brand but not the platform.

Arjuninfra: a real-estate ad with no "Book a site visit" — the CTA rubric literally downgraded imperatives.

The number

We turned the 6 clusters into 6 binary checks and code-graded the corpus. "Production-grade" = a founder ships it to Meta with zero edits.

The insight that set the target: the two "good" anchors were ceilings reached through many edits, not first-gen floors. So the goal wasn't "be great" — it was clear a shippable floor on the first try: 0% → 50%+. Existing user-iteration UX carries floor → ceiling.

Every failure had a literal address

The leak map traced each failure mode to the exact line in the agent's prompts and skills. Three shapes of cause — and none of them were "the model is bad."

Absent instruction

The prompt never told the agent to check. research.md has no redirect / locale detection; the 14 art workflows/ have zero mention of uploaded photos, so refs get silently skipped.

Wrong instruction

The prompt actively taught the failure. Art workflows say "10% text max" — assuming a post-overlay step that doesn't exist (Nano-Banana renders text natively), so the hook gets dropped. The CTA table labels "Apply now" as WEAK.

Frame drift

The orchestrator called itself "a pipeline coordinator." So it coordinates but never judges — no vertical gate, no shippability check, nothing that rejects a bad output before it ships.

The root cause under all six wasn't the model — it was weak handoffs between stages and an orchestrator that never judged. So the fix isn't six patches. It's a redesign with a faithfulness contract at every handoff and a critic that gates before money is spent. → That's "The agent."
